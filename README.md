# Deep Learning with PyTorch

Hands-on implementation of deep learning fundamentals using **PyTorch**, covering tensors, neural network workflows, classification, and computer vision.

This repository documents my learning journey as I build a stronger foundation in **Deep Learning, Neural Networks, Computer Vision, and PyTorch**.

---

## 🚀 What I'm Learning

The repository currently covers:

### 🔹 PyTorch Fundamentals

* PyTorch tensors and tensor operations
* Tensor dimensions, shapes, and data types
* Device management (CPU/GPU)
* PyTorch workflow fundamentals
* Training and testing workflows

### 🔹 Neural Networks & Classification

* Building neural networks with `nn.Module`
* Model architecture and layers
* Activation functions
* Binary classification
* Logits and prediction probabilities
* Loss functions
* Optimizers
* Model evaluation
* Train/test datasets

### 🔹 Computer Vision with PyTorch

* Working with image datasets
* `torchvision` and image transformations
* `Dataset` and `DataLoader`
* Image tensors and batch dimensions
* Building CNNs with `nn.Conv2d`
* Pooling layers with `nn.MaxPool2d`
* Convolutional neural network architecture
* Training and evaluating image classification models
* FashionMNIST image classification
* TinyVGG-style CNN architecture
* Making predictions and visualizing model results

> **Current focus:** Building a strong foundation in PyTorch Computer Vision before moving on to **Transfer Learning** and more advanced image classification projects.
