# Deep Learning with PyTorch

Hands-on implementation of deep learning fundamentals using **PyTorch**, covering tensors, neural network workflows, and binary classification.

This repository documents my learning journey as I build a stronger foundation in **Deep Learning, Neural Networks, and PyTorch**.

---

## 🚀 What I'm Learning

The repository currently covers:

- PyTorch tensors and tensor operations
- Tensor dimensions, shapes and data types
- PyTorch workflow fundamentals
- Building neural networks with `nn.Module`
- Model architecture and layers
- Binary classification
- Activation functions
- Logits and prediction probabilities
- Loss functions
- Optimizers
- Model evaluation
- Train/test datasets
